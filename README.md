# The Linguistic Blindspot

**Evaluating Logic Degradation in Frontier LLMs Using Contextual Negation Riddles**

This research examines how frontier large language models handle linguistic traps, layered double negatives, and semantic misdirection.

## Overview

The project introduces an adversarial evaluation dataset of 150 structured logic riddles and a multi-tier grading rubric for assessing model reasoning steps and locating failures in logical cascades. The framework identifies cases where models give confident but incorrect answers, and is intended to surface semantic edge cases that conventional automated benchmarks may miss.

## Relevance

The evaluation framework may support reinforcement learning from human feedback (RLHF) data pipelines by helping identify difficult semantic examples for review.
